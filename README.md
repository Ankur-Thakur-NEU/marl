# Marl

An interactive walkthrough for people in the United States who might fund a pre-sample hiking brand.

Open `index.html`. Arrow keys move between slides. `G` opens the grid. `?` shows the keys.

This is not a valuation and not a price list. Shelf prices and duty lines are from October 2026 and have to be re-read before anyone wires money. The company has no sample, no signed factory, and no test result with its name on it.
