# Marl

An interactive walkthrough for people in the United States who might fund a pre-sample hiking brand.

Open `index.html` in a browser. Arrow keys move between slides. `G` opens the grid. `?` shows the keys.

Shelf prices and duty lines are from October 2026. This is not a valuation. There is no sample, no signed factory, and no test result with the brand's name on it.
